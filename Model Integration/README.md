# Model Integration

This module contains the iSARTHI road-damage detection pipeline.

## Features
- YOLOv8-based road hazard detection
- Raspberry Pi camera integration
- Pothole detection and confidence reporting
- Integration-ready hazard events for sensor fusion
- V2V alerts and dashboard publishing

## Requirements
- Python 3
- Ultralytics YOLO
- OpenCV
- NumPy
- Raspberry Pi camera tools

## Usage
Configure the model checkpoint and detection class names,
then run the appropriate Python detection script.
